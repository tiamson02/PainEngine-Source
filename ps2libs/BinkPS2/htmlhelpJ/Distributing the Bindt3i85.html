MacOS での Bink 共有ライブラリの配布

説明

Bink を使用するアプリケーションを配布する場合は、Bink Shared Library をアプリケーションと同じフォルダに置きます。

Bink Shared Library をシステムフォルダまたは機能拡張フォルダに入れないでください。Bink Shared Library は、必ずアプリケーション フォルダに置いてください。
