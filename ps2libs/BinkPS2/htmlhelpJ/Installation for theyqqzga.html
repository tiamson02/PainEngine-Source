Bink SDK 1.8b

ソニー PS2 へのインストール

説明

Bink SDK CD を Windows 9x または Windows NT の開発マシンに挿入すると、Bink のインストーラが自動的に起動します。Win32 マシンで自動再生ができない場合は、Bink SDK CD のルート ディレクトリにあるインストール プログラム BinkPS2.exe を手動で起動します。

大部分のインストール オプションは自動的に選択されます。インストール ディレクトリなどのパラメータを変更しないかぎり、ユーザーが入力する必要はほとんどありません。
