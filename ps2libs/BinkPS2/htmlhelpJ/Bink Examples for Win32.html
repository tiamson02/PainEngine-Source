Bink SDK 1.8b

Win32 用の Bink のサンプル

説明

Bink SDK には、Win32 用のプログラムのサンプルがいくつか用意されています。IDE ベースの環境でこれらのサンプルを作成するには、新規プロジェクトを作成して適切な C のソース ファイル (ExamW32.C、ExamMSS.C、または ExamDDP.C) をインクルードし、次に Windows 版 Bink のインポート ライブラリをプロジェクト (BinkW32.LIB) に追加するだけです。

練習用のサンプル ファイルは次のとおりです。

BinkBuffer API を使用したプレイヤーのサンプルについては、ファイル ExamW32.C を参照してください。

Miles Sound System と BinkBuffer API を使用したプレイヤーのサンプルについては、ファイル ExamMSS.C を参照してください。

DirectDraw を使用したプレイヤーのサンプルについては、ファイル ExamDDP.C を参照してください。

OpenGL で Bink のアルファ平面を使う方法については、ファイル ExamAlph.C を参照してください。このサンプルでは OpenGL や Direct3D を使用できます。OpenGL は、ファイル GLRAD3D.C にリンクするだけで使用できます。

Direct3D 9 で Bink のアルファ平面を使う方法については、ファイル ExamAlph.C を参照してください。このサンプルでは OpenGL や Direct3D を使用できます。Direct3D は、ファイル DX9RAD3D.CPP にリンクするだけで使用できます。

Direct3D 8 で Bink のアルファ平面を使う方法については、ファイル ExamAlph.C を参照してください。このサンプルでは OpenGL や Direct3D を使用できます。Direct3D は、ファイル DX8RAD3D.CPP にリンクするだけで使用できます。

Direct3D 7 で Bink のアルファ平面を使う方法については、ファイル ExamAlph.C を参照してください。このサンプルでは OpenGL や Direct3D を使用できます。Direct3D は、ファイル DX7RAD3D.CPP にリンクするだけで使用できます。
