Bink SDK 1.8b

ニンテンドー ゲームキューブでの Bink のサンプル

説明

Bink SDK には、ニンテンドー ゲームキューブ用のプログラムのサンプルがいくつか用意されています。SN システムや CodeWarrior でこれらのサンプルを作成するには、新規プロジェクトを作成して適切な C のソース ファイル (ExamNbb.C、ExamNTex.C または ExamNAlf.C) をインクルードし、次にニンテンドー ゲームキューブ版 Bink のスタティック ライブラリをプロジェクト (BinkNGC.a) に追加するだけです。

練習用のサンプル ファイルは次のとおりです。

Bink を使用して直接ゲームキューブの YUV バック バッファにビデオを表示するサンプルについては、ファイル ExamNbb.C を参照してください。このサンプルは、ビデオのレンダリングに GPU を使わないためきわめてシンプルです。バック バッファに直接ブラストするだけです。また、YUV フォーマットから変換する必要もないため、処理速度も格段に向上します。

Bink を使用してテクスチャに解凍してからテクスチャを画面上にレンダリングするサンプルについては、ファイル ExamNTex.C を参照してください。このサンプルでは 3D ラッパーを使用するので、必ずファイル NGCRAD3D.C もプロジェクトに追加してください。Bink では、YVR フォーマットからゲームキューブのスウィズルされたフォーマットに BinkCopyToBuffer 関数で直接変換します。そのため、テクスチャを即座にレンダリングできます。

Bink でアルファ画像を使用してテクスチャを画面にレンダリングするサンプル プログラムについては、ファイル ExamNAlf.C を参照してください。このサンプルでは 3D ラッパーも使用するので、必ずファイル NGCRAD3D.C もプロジェクトに追加してください。テスト用の小さいサイズのアルファ ムービーを当社の FTP サイト <ftp://ftp.radgametools.com/bink> からダウンロードできます。

これらのサンプルでは、ゲームキューブを設定するために必ず 1 つの簡単なファイルを使用します。サンプルのプロジェクトには、NGCDemo.c も加えてください。
