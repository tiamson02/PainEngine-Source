Bink SDK 1.8b

BinkNextFrame

BinkNextFrame 関数は、Bink ファイルのビデオの次のフレームに移動します。

void BinkNextFrame(
  HBINK bink
);

入力パラメータ

bink
Bink ハンドルを指定します。

説明

この関数により、実際に次のフレームに移動します。通常はフレームを BinkDoFrame で解凍してからこの関数を呼び出し、画面にブリットします。遅延ループ BinkWait の前の再生ロジック内で、この関数が最後の関数である必要があります。BinkWait ループで待つ前に、必ずこの関数を呼び出してください。呼び出さないと、ぎくしゃくした動きで再生されます。たとえば、正しい再生ロジックのサンプルは次のとおりです。

for( i=0 ; ; i++ )
{
  BinkDoFrame( bink );
  BinkNextFrame( bink );        //***** この行が BinkWait 遅延ループの前に置かれていることに注意
  while ( BinkWait( bink ) ) ;  //***** この行が BinkWait 遅延ループの後に置かれていることに注意
}

次は、正しくない再生ロジックのサンプルです。

for( i=0 ; ; i++ )
{                             //***** 間違った再生ループのサンプル
  BinkDoFrame( bink );
  while (BinkWait( bink ) ) ; //***** 誤り: この行は BINKNEXTFRAME の後に置く必要がある
  BinkNextFrame( bink );      //***** 誤り: この行は BINKWAIT ループの前に置く必要がある
}

Bink ファイルの最後のフレームでこの関数を呼び出すと、Bink は最初のフレームに戻ってループを繰り返します。つまり、アニメーションを 1 回だけ再生するには (ループさせずに)、一番最後のフレームに特別なロジックを追加して、この関数を呼び出さないようにする必要があります (そうしないと、Bink がファイルの先頭に戻るための遅延がビデオの末尾で発生します)。たとえば、Bink ファイルを 1 回だけ再生する単純な再生ループは、次のとおりです。

for( i=0 ; ; i++ )
{
  BinkDoFrame( bink );
  if ( i == bink->Frames )  // ファイルの最後で BinkNextFrame ループから抜ける
    break;
  BinkNextFrame( bink );
  while ( BinkWait( bink ) ) ;
}
