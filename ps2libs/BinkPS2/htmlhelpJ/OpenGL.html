OpenGL

説明

OpenGL は業界標準の 3D グラフィック API です。3D グラフィック カードを制御するために使用されます。

OpenGL を使用すると、高速アルファ平面制御による透過ビデオ再生が可能になります (例は ExamAlph.C と GLRAD3D.C を参照)。

OpenGL の詳細については、Web サイト GLSetup を参照してください。
