ソニー PS2 での CPU の共有

説明

ソニー PS2 では、CPU を OS と共用する必要はまったくありません。これはコンソール上の作業で得られる特別なメリットで、CPU を必要なだけ使い切ることができます。

これは、ソニー PS2 での一般的な Bink 再生ループがきわめて単純であることを意味します。Bink は BinkWait 関数でタイミングを処理するので、必要な処理は、ビデオの再生中は常にこの関数を確認するということだけです。

したがって、ソニー PS2 での再生の簡単なサンプルは次のようになります。

for ( ; ; )
{
   // 再生をチェック
   if ( !BinkWait( bink ) )
   {
     BinkDoFrame( bink );
     // 前のフレームがアップロードされるまで待つ
     wait_for_DMA_to_complete();
     // RGB32 にコピー
     BinkCopyToBuffer( bink, ... );
     // ビデオ フレームのアップロードを開始
     start_DMAing_the_video_frame();
     // 次のフレームに移動
     BinkNextFrame( bink ); 
   }
 }
}
