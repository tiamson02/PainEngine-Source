Bink SDK 1.8b

GNU/Linux へのインストール

説明

Bink SDK は、zip 形式の圧縮ファイルで提供されます。このファイルを使用するには、ディレクトリに解凍するだけです。

インストールが完了したら、html フォルダにあるファイル index.html をクリックして、オンラインでアクセスできます。このファイルへのリンクを作成することもできます。
