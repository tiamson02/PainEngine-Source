Bink SDK 1.8b

Win32 へのインストール

説明

Bink SDK CD を自動再生が可能なマシンに挿入すると、Bink のインストーラが自動的に起動します。マシンで自動再生ができない場合は、Bink SDK CD のルート ディレクトリにあるインストール プログラム Bink.exe を手動で起動します。

インストーラが起動すると、インストール オプションが表示されます。以下の項目があります。

1) Bink SDK のインストール。Bink Video を組み込むプログラムをビルドするために必要なファイルをインストールします。

2) RAD Video Tools のインストール。ビデオ ファイルを Bink フォーマットや Smacker フォーマットで圧縮するツールをインストールします。

3) Miles Sound System デモのインストール。RAD のオーディオ技術製品のデモンストレーションをインストールします。

4) Granny デモのインストール。RAD の 3D アニメーション製品のデモンストレーションをインストールします。

大部分のインストール オプションは自動的に選択されます。インストール ディレクトリなどのパラメータを変更しないかぎり、ユーザーが入力する必要はほとんどありません。
