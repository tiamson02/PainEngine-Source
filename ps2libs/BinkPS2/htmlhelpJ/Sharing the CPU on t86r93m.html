ニンテンドー ゲームキューブでの CPU の共有

説明

ニンテンドー ゲームキューブでは、CPU を OS と共用する必要はまったくありません。これはコンソール上の作業で得られる特別なメリットで、CPU を必要なだけ使い切ることができます。

これは、ニンテンドー ゲームキューブでの一般的な Bink 再生ループがきわめて単純であることを意味します。Bink は BinkWait 関数でタイミングを処理するので、必要な処理は、ビデオの再生中は常にこの関数を確認するということだけです。

したがって、ニンテンドー ゲームキューブでの再生の簡単なサンプルは次のようになります。

for ( ; ; )
{
   // 再生をチェック
   if ( !BinkWait( bink ) )
   {
     // 次の Bink フレームの処理に進む
     Show_next_frame( bink, texture );
   }
 }
}
