Bink SDK 1.8b

はじめに



Bink SDK へようこそ。お買い求めくださり、ありがとうございます。

本ドキュメントでは、Win32、ソニー PS2、Xbox、ゲームキューブ、Linux、MacOS 上のプログラマを対象として Bink SDK について説明します。本ドキュメントにはかなりの労力が費やされています。使いこなせるようになるために役立てば幸いです。参考になったこと、参考にならなかったことについてお知らせください。Bink API 本体と同様に、ドキュメントの改善にも勤めていきます。そのためにはお客様のご意見が大切です。

またこのマニュアルも常に改訂されることにご注意ください。Bink の新バージョンを入手したらドキュメントを確認して、見落としのないようにしてください。

このマニュアルの「Bink の概要」では、Bink の概要について説明します。当社のビデオ API を初めてご使用の場合は、この章からご覧ください。Bink と Smacker はよく似ているので、Smacker のユーザーは省略してかまいません。

「Win32 版の Bink」では、面倒な一方で独特の魅力を持つ Win32 プラットフォームでの Bink の使用法の詳細について説明します。ここでは、Microsoft OS での Bink の使用法について詳しく説明します。

「ソニー プレイステーション 2 版 Bink」では、ソニー PS2 のビデオ ゲーム コンソールでの Bink の使用法を詳しく説明します。この章では、コンソール (プログラムしにくくても、使い甲斐があります) での Bink の使用法を詳しく説明します。

「ニンテンドー ゲームキューブ版 Bink」では、ニンテンドー ゲームキューブのビデオ ゲーム コンソールでの Bink の使用法を詳しく説明します。ここでは、小さくても重要なコンソールでの Bink の使用法について詳しく説明します。

「Xbox 版 Bink」では、Microsoft Xbox のビデオ ゲーム コンソールでの Bink の使用法を詳しく説明します。ここでは、この優れた環境での Bink の使用法について詳しく説明します。

「MacOS 版の Bink」では、MacOS 9 プラットフォームと MacOS X プラットフォームでの Bink の使用法について詳しく説明します。ここでは、Apple の OS での Bink の使用法について詳しく説明します。

「Linux 版 Bink」では、Linux OS での Bink の使用法を詳しく説明します。ここでは、オープン ソース OS での Bink の使用法について詳しく説明します。

最後に、本ドキュメントのリファレンス セクションについて概説します。リファレンスでは、Bink API とブリッティング API (BinkBuffer API) 両方のすべての機能について説明します。

なお、オンライン マニュアルの一部は冊子のマニュアルには記載されていません。オンライン マニュアルからハイパーリンクおよびクロス リファレンスしてある説明を確認してください。膨大な情報を入手できます。

わかりにくい点、ご満足いただいた点、ご不満な点、次のバージョンに対するご要望など、Bink を使用した感想をお送りください。お客様のご意見によって Bink はこれからも活力を保ち、楽しく使用でき、強力であり続けることができます。

再度、感謝を申し上げます。
