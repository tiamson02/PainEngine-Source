Bink SDK 1.8b

MacOS へのインストール

説明

Bink SDK は、MacBinary 形式の圧縮アーカイブで提供されます。Bink SDK CD にあるファイル BinkSDK.sit.bin をダブルクリックするだけでインストールできます。

インストールが完了したら、Bink SDK フォルダにある Bink SDK Help のエイリアスをクリックして、オンラインでアクセスできます。

この CD には、Windows 用の RAD Video Tool も入っています。Bind 形式にファイルを圧縮するには、Window マシンにこれらのツールをインストールしてください。
