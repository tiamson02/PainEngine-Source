Bink SDK 1.8b

Direct3D

説明

Direct3D は、Microsoft が提供する 3D グラフィック API です。3D グラフィック カードを制御するために使用されます。

Direct3D を使用すると、高速アルファ平面制御による透過ビデオ再生が可能になります (DirectX 8 の例は ExamAlph.C と DX9RAD3D.CPP または DX8RAD3D.CPP を参照)。

ビデオ フレームを Xbox 上で再生する場合は、必ず Direct3D を使用します。これは、現在 2D のブリッティング API が提供されていないためです。ただし、Xbox は線形の非 2 乗テクスチャをサポートするため、ビデオの再生での問題はまったくありません。

Direct3D の詳細については、Web サイト Microsoft DirectX を参照してください。
