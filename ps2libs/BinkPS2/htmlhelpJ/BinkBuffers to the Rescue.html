BinkBuffer による解決

説明

では、どの技術を使用すればよいのでしょうか。Bink に組み込まれたソフトウェア、オーバーレイ、オフスクリーン バッファのどれでしょうか。この選択で迷った場合のために、Bink には BinkBuffer API があります。BinkBuffer によって DirectDraw の複雑さが隠され、異なる色空間の間の切り替えが簡単になります。Bink プレイヤー、サンプル ExamW32.C、サンプル ExamMSS.C は、いずれも BinkBuffer API を使用することによって簡単に Bink フレームを表示しています。

しかし、BinkBuffer API はかなり高レベルなので、すでに DirectDraw をアプリケーションで実行している場合は、BinkBuffer を完全にスキップし、内部の Bink ソフトウェア ルーチンを使用してプライマリ サーフェスまたはセカンダリ サーフェスに直接変換することをお勧めします。この種類の再生のサンプルについては、ExamDDP.C file を参照してください。

また、3D システムがアクティブな場合は BinkBuffer API を使用しないように注意してください。BinkBuffer API は比較的新しい 3D カードでは作動しますが、古いカード (または古いドライバ) では 2D データを 3D ウィンドウにブリットできないので、画面が表示されません。
