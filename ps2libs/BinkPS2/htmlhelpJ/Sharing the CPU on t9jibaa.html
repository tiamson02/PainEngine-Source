Xbox での CPU の共有

説明

Xbox では、CPU を OS と共用する必要はまったくありません。これは Xbox を使う利点で、CPU を独占できるということは間違いのないメリットです。

そのため、Xbox での Bink 再生ループは通常きわめてシンプルになります。Bink は BinkWait 関数を使用してタイミングを処理するので、ビデオの再生中はこの関数をチェックするだけで済みます (ただし、ビデオが 29.97 fps で作成されていて、ページ フリップ コントロールでフレーム レートを管理できる場合は除きます)。

したがって、Xbox での再生の簡単なサンプルは次のようになります。

for ( ; ; )
{
   // 再生をチェック
   //
   // ビデオが正確に 29.97 fps で
   //   作成されていると、
   //   calling BinkWait を呼び出すことがなく
   //   ページ フリップが再生速度を
   //   制御するので
   //   パフォーマンスが向上する
   //
   if ( !BinkWait( bink ) )
   {
     // 次の Bink フレームの処理に進む
     Show_next_frame( bink, linear_texture );
   }
 }
}
