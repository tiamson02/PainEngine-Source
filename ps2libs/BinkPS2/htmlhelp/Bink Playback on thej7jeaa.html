Bink Playback on the Xenon

Discussion

Video playback on the Xenon is pretty easy compared to a PC - the hardware is damn fast and, most importantly, it is constant. If it plays back perfectly on your machine, then it will on everyone else's too!

For playback on Xenon, you definitely want to use pixel shaders to do the YUV to RGB colorspace conversion. If you do this, then you can have Bink decompress directly into Direct3D 8-bit luminance textures (two sets of 3 of them - one for Y, cR, cB). Then, you simply render after calling BinkDoFrame. This requires the use of the BinkGetFrameBuffersInfo and BinkRegisterFrameBuffers functions. We've supplied the shaders and all the code to render them in the BinkTextures.CPP file, and the ExamXenon.CPP file shows how to draw them.

If you need to use an alpha plane, then Bink still has you covered. We've supplied a pixel shader to read and blend the alpha planes too. See the ExamXenA.CPP to see how to display an alpha video.

The Xenon's 3D hardware is terrific, you can display HDTV video with no CPU hit for color conversion at all.
